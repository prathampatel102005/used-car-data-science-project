# Used Car Data Science Project

An end-to-end used-car analytics project combining Python data preparation, SQL analysis, machine-learning classification, and a Tableau dashboard.

## Project overview

This repository uses two related CSV tables supplied for the project. They are linked by the unique `vehicle_uid` key.

- `data/vehicle_info.csv`: 4,340 vehicle records with 9 columns.
- `data/vehicle_sales.csv`: 4,340 sales records with 5 columns.
- `data/Cars_info.csv`: merged analysis dataset with 4,340 rows and 13 columns, created by joining the two tables on `vehicle_uid`.

The merged dataset is used by the Python notebooks. The two source tables are used by the SQL queries.

## Dataset columns

### `vehicle_info.csv`
`vehicle_uid`, `name`, `year`, `fuel`, `seller_type`, `transmission`, `owner`, `brand`, `car_age`

### `vehicle_sales.csv`
`vehicle_uid`, `selling_price`, `km_driven`, `price_category`, `km_category`

### `Cars_info.csv`
The merged dataset contains all columns from both tables, with one row per `vehicle_uid`.

## Tools and technologies

- Python: Pandas, NumPy
- Data visualization: Matplotlib, Seaborn
- Machine learning: Scikit-learn (SVC and Random Forest classification)
- SQL: joins, filtering, grouping, aggregate functions, `HAVING`, and subqueries
- Tableau: packaged workbook (`.twbx`)

## Run the project

### 1. Download or clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/used-car-data-science-project.git
cd used-car-data-science-project
```

### 2. Create an environment and install dependencies

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install packages:
```bash
pip install -r requirements.txt
```

### 3. Run the Python notebooks

Start Jupyter from the repository root:

```bash
jupyter notebook
```

Open `notebooks/01_data_cleaning_and_preparation.ipynb` first, then `notebooks/02_price_category_classification.ipynb`.

The notebooks load the merged dataset using `../data/Cars_info.csv`. The data preparation notebook exports the merged and split CSVs back into the `data/` folder.

### 4. Run the SQL analysis

Create a MySQL database and import `data/vehicle_info.csv` and `data/vehicle_sales.csv` as tables named `vehicle_info` and `vehicle_sales`. Then run `sql/vehicle_analysis_queries.sql`.

### 5. Open the Tableau dashboard

Open `tableau/used_car_analysis_dashboard.twbx` with Tableau Desktop or Tableau Reader. If Tableau reports a missing data source, use the packaged extract or reconnect the workbook to the included CSV files.

## SQL questions covered

1. Vehicles using Diesel fuel.
2. Vehicle name, year, and brand.
3. Sales below ₹5,00,000.
4. Fuel types with average selling price above ₹6,00,000.
5. Brands with more than 50 listed vehicles.
6. Transmission types with average selling price above ₹7,00,000 and at least 30 vehicles.
7. Diesel price categories with average kilometres driven above 75,000 and more than 20 vehicles.
8. Vehicles priced above the overall average selling price.
9. Brands with average selling price above Toyota's average.
10. Fuel types with total selling price above Petrol's total.
